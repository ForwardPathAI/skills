# Deprecated

Skills we no longer use. They stay installable by name until deleted, but nothing in `engineering/` links to them. Each entry names what replaced it, if anything.

- **[plan-refiner](./plan-refiner/SKILL.md)**: Harden an existing Cursor plan so a weaker executor model can implement it without judgment calls — hunt unknowns, resolve them via codebase/web research or a one-gap-at-a-time user interview, anticipate non-obvious scenarios, and rewrite the plan file in place as unambiguous, verifiable statements. Replaced by [issue-writer](../engineering/issue-writer/SKILL.md) tickets scoped by behavior and [execute](../engineering/execute/SKILL.md)'s orient step.
- **[plan-context-imager](./plan-context-imager/SKILL.md)**: Gather the codebase context a plan depends on, render it into dense PNG pages via pxpipe's `renderTextToImages`, and embed the images plus a per-page index into the plan so the executor reads them instead of re-grepping the codebase each step. Replaced by [execute](../engineering/execute/SKILL.md): the executor reads the current code instead of a snapshot of it.
- **[speclang-writer](./speclang-writer/SKILL.md)**: Turn a plan into a SpecLang specification — a structured, natural-language Markdown document (the single source of truth) that captures a system's behavior and its pinned implementation details so an AI toolchain or executor can generate the code from the spec. Replaced by issue-writer's [spec step](../engineering/issue-writer/splitting.md).
- **[cloud-agent-triage](./cloud-agent-triage/SKILL.md)**: Evaluate whether Linear tickets suit autonomous Cursor cloud agents (why yes / why not), triage a repo's backlog honoring blockers, and optionally delegate the ready ones to Cursor. Replaced by [ticket-refiner](../engineering/ticket-refiner/SKILL.md) for readiness and [execute](../engineering/execute/SKILL.md) for building tickets.
- **[architecture-to-linear-plan](./architecture-to-linear-plan/SKILL.md)**: Turn the poc-to-product-architecture deliverable (canvas + DOCX) and any web-ui/mobile-ui mockups into a delivery plan — Linear milestones with proposed timelines and executable functional + design tickets — then, once approved, create the project, milestones, and issues in Linear via the Linear MCP. Replaced by issue-writer's [spec step](../engineering/issue-writer/splitting.md).
- **[backlog-hygiene](./backlog-hygiene/SKILL.md)**: Scan a Linear project's backlog for relevance — flag stale, already-shipped, or duplicated issues using update age, code/PR evidence, and ticket similarity — then apply confirmed actions one at a time. No replacement.
- **[cloud-agent-pr-stats](./cloud-agent-pr-stats/SKILL.md)**: Count PRs opened by cloud coding agents (Cursor, Codex, Devin, Claude, Copilot) across a GitHub org, by branch-name prefix. No replacement.
- **[effort-estimate](./effort-estimate/SKILL.md)**: Produce a bottom-up engineering-hours estimate for a feature, workstream, or software build, with explicit scope assumptions and quantified price levers. No replacement.
- **[eng-report-effort-estimate](./eng-report-effort-estimate/SKILL.md)**: Generate the combined Engineering Report + Effort Estimate document in Notion for a custom build — understanding check with price levers, gated generation, fixed-price effort estimation with internal QA phase, and a post-generation coverage audit. No replacement.
- **[engineering-projects-on-track](./engineering-projects-on-track/SKILL.md)**: On-track % for ForwardPath Engineering Linear projects in In Progress or UAT, from the latest project status update. No replacement.
- **[linear-backlog-grill](./linear-backlog-grill/SKILL.md)**: Grill Linear project backlogs for execution readiness — grade tickets, interview for missing specification, split oversized work, and rewrite issues to pass the agent-ready bar. Replaced by [ticket-refiner](../engineering/ticket-refiner/SKILL.md), one ticket at a time.
- **[poc-to-product-architecture](./poc-to-product-architecture/SKILL.md)**: Turn a SOW and POC repo into a production system-design canvas — architecture, gap audit, Azure resource map, Bicep skeleton, security/reliability, and cost estimate, constrained to the Forward Path stack and customer-deployable Bicep. No replacement.
- **[review-mp4](./review-mp4/SKILL.md)**: Understand an mp4 (local or URL): extract frames with ffmpeg, pick the sharpest in-focus frame per window via variance-of-Laplacian blur detection (Python or Node), then read them to answer questions. No replacement.
- **[setup-preview-env](./setup-preview-env/SKILL.md)**: Set up ephemeral per-pull-request Azure preview environments for a containerized app — shared/per-PR Terraform, GitHub Actions deploy/teardown, auth redirects, and runbooks distilled from the ButtconRAG preview lane. No replacement.
